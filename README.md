# منصة منافذ التشغيلية لإدارة أعمال وبرامج الأقسام

**جمعية رعاية الأيتام بمحافظة حفر الباطن (تراؤف)**

المنصة الإلكترونية الداخلية الموحدة لتنظيم وإدارة وجدولة أعمال وبرامج الأقسام الأربعة:
1. **قسم البناء التربوي**
2. **قسم الدعم العلمي**
3. **قسم المساندة والتحفيز**
4. **قسم تنمية المواهب**
*(مع قابلية إضافة أقسام جديدة مستقبلاً مباشرة من لوحة الإدارة دون إعادة بناء النظام)*

## المزايا والوحدات التشغيلية

- **قاعدة بيانات موحدة مترابطة** مستوردة من الملفات الرسمية الستة (خالية تمامًا من البيانات المالية وأنشطة الرواتب والبدلات).
- **الفصل الذكي بين التخطيط والتنفيذ:** قراءة الخلايا الخضراء (`#DFF0D8`) كمواعيد تنفيذ مخططة حسب الشهر والأسبوع، مع استكمال الجدولة التنفيذية دون إعادة إدخال بيانات التخطيط.
- **محرك كشف التعارضات الثماني الفوري:** يفحص (الموظف، المعلم، الإشراف اليومي، القاعة، الفئة/النطاق، الأوقات الثابتة كالصلوات والوجبة والحافلات، البرامج النوعية، وتزامن الأقسام) ويعرض جميع التعارضات معًا مع اقتراح **بدائل ذكية خالية من التعارض**.
- **دورة طلبات الاستثناء الإلكترونية الكاملة:** رفع طلب الاستثناء بنقل تلقائي للبيانات، إحالته لأصحاب الرأي المحددين، شاشة مقارنة جنباً إلى جنب، الاعتماد النهائي، و**معالجة البرامج المتأثرة** عبر 12 إجراءً تشغيليًا دون إلغاء تلقائي صامت.
- **مركز التشغيل اللحظي + شاشة «جدولي اليوم» الزمنية للموظفين + بطاقة الموظف الشاملة**.
- **التقويم التخطيطي الشهري والسنوي + برامج هذا الأسبوع + برامج الأسبوع القادم + الجدول التشغيلي الموحد**.
- **إدارة الفترات، مراجعة اختلافات البيانات بين الملفات، أداة إعادة استيراد وتحديث ملفات Excel مع فحص الفروقات وحفظ النسخ السابقة، مركز الإشعارات، وسجل الإجراءات غير القابل للحذف (Audit Log)**.
